# Agentic AI Patterns

## Single tool-using agent
Use when one agent can complete the workflow safely.

## Router + specialists
Use when requests belong to clearly different domains.

## Supervisor + specialists
Use when a single user goal requires multiple bounded capabilities.

## Planner + executor
Use when a complex goal must be decomposed before action.

## Human approval gate
Use when actions can cause meaningful business, financial, legal, or security impact.

## Retrieval agent
Use when answers must be grounded in changing or private knowledge.

## Deterministic workflow + AI steps
Often preferable to a fully autonomous agent. Use AI only where judgment or language understanding is actually needed.
