# Prototype to Production Roadmap

## Phase 1 — Learning prototype
Local tools, deterministic routing, local RAG, optional Ollama.

## Phase 2 — Team pilot
Real APIs, authentication, trace store, evaluation suite, approval workflow.

## Phase 3 — Controlled production
Model gateway, RBAC, secrets management, rate limits, audit logs, SLOs, incident response.

## Phase 4 — Enterprise platform
Multi-tenancy, centralized governance, agent registry, tool registry, cost allocation, model routing, continuous evaluation.
