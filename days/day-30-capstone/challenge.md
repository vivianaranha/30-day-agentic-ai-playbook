# Day 30 Challenge

## Challenge

Extend the Super Agent with one new specialist, one tool, three tests, and one evaluation dataset.

## Definition of done

- The example runs.
- At least one test or manual verification is completed.
- Failure behavior is considered.
- Security implications are documented.
- You can explain the architecture without relying on framework terminology.

## Stretch goal

Add one improvement that reduces risk, latency, cost, or complexity.
